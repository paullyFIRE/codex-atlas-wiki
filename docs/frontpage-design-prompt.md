## Content Ideas for Design Exploration

- **Hero of the Week / Featured Hero**: Rotating spotlight card on the hero section linking to a top-tier hero page (e.g., Radiant Warrior)
- **Search bar**: Prominent search input below the H1 for instant entity lookup
- **Rank of the day**: Show today's featured S+/S tier hero with ranking badge
- **What's New / Changelog**: Timestamped list of recently added or updated content
- **Quick links row**: Icon shortcuts to most-visited pages (Tier List, Gem Guide, Beginner Guide, Compare)
- **Dark mode toggle** (already have dark-gold theme)
- **Mobile hamburger menu** for the nav
- **Last updated date**: "Data last updated June 2026" for freshness signal
- **YouTube embed**: Link or embed top Klown Kollege video

Design the frontpage layout showing:
